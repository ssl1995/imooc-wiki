# 古树名木多模态检索系统 Web界面设计总结

## 一、完成的工作

### 1. 图4.8 数据上传页面 (`admin-data-upload.vue`)

**页面功能**：管理员用于录入古树名木数据

**布局结构**：
- 左侧（占14/24）：基础信息录入表单
  - 古树名称（必填）
  - 物种分类（下拉选择）
  - 地理位置（经纬度输入）
  - 树龄、树高
  - 保护级别（单选）
  - 拍摄日期
  - 备注
- 右侧（占10/24）：图像上传区域
  - 拖拽上传组件
  - 图片预览区域
  - 提交/重置按钮

**技术特点**：
- 使用 `a-upload-dragger` 实现拖拽上传
- 表单验证（必填项检查）
- 图片预览和删除功能

### 2. 图4.9 检索页面 (`retrieval.vue`)

**页面功能**：用户进行多模态检索

**三种检索模式**：

#### 模式1：I2I (Image-to-Image) - 以图搜图
- 上传查询图像
- 设置返回结果数和相似度阈值
- 显示相似图片列表（带相似度百分比标签）

#### 模式2：I2L (Image-to-Location) - 以图搜位置
- 上传查询图像
- 返回预测位置（经纬度）
- 显示置信度进度条
- 显示误差范围和地址描述
- 地图显示区域（占位）

#### 模式3：L2I (Location-to-Image) - 以位置搜图
- 输入经纬度坐标
- 选择搜索半径（<1km, <5km, <10km, <50km）
- 快速选择按钮（北京、上海、成都、广州）
- 显示附近古树列表（带距离标签）

**界面特点**：
- 使用 `a-radio-button` 实现模式切换
- 左侧输入区域 + 右侧结果展示的经典布局
- 卡片式结果展示，悬停上浮效果
- 相似度标签颜色根据数值变化

## 五、样式设计

### 颜色方案
- 主色调：#1890ff（Ant Design 蓝色）
- 背景：渐变 `linear-gradient(135deg, #f5f7fa 0%, #c3cfe2 100%)`
- 成功色：#52c41a
- 卡片背景：#ffffff

### 布局特点
- 响应式栅格布局（a-row + a-col）
- 左侧输入（8/24），右侧结果（16/24）
- 卡片圆角 12px
- 阴影 `0 4px 12px rgba(0, 0, 0, 0.08)`

### 交互效果
- 图片悬停上浮 `transform: translateY(-4px)`
- 相似度标签颜色分级（绿→青→蓝→橙）
- 拖拽上传状态反馈
