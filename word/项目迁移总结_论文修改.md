## 🎨 算法图结构（第三章）

### 图3.1 - 模型整体架构
```
输入层 → 特征提取 → 哈希层 → 多模态融合 → 检索输出
  │         │          │          │           │
  ▼         ▼          ▼          ▼           ▼
图像    ResNet/ViT   Hash      图文特征    Top-K
文本    BERT/Text    Layer      对齐        结果
        Encoder                         
```

**关键模块：**
- 多骨干网络：ResNet-50 / ViT / EfficientNet
- 哈希层：全连接层 + Tanh激活 → 128位二进制码
- 损失函数：Triplet Loss + Contrastive Loss + Quantization Loss
- 多模态融合：图像特征(512维) + 文本特征(256维) → 融合特征

### 图3.2 - 损失函数计算过程
- Triplet Loss：三元组学习（Anchor-Positive-Negative）
- Contrastive Loss：对比学习拉近/推远样本
- Quantization Loss：量化损失使哈希码接近±1

### 图3.3 - 多模态融合策略
- 特征层融合：拼接/加权/双线性融合
- 跨模态注意力：图文特征对齐
