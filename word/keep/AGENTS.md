## 三、饮食原则

### 3.1 每日摄入目标

| | 训练日 | 休息日 |
|:---|:---|:---|
| 热量 | 2200 kcal | 1900 kcal |
| 蛋白质 | **170g** | **170g** |
| 碳水 | 220g | 150g |
| 脂肪 | 60g | 55g |
| 饮水 | **3.0L** | **2.5L** |

> 蛋白质170g是不可动摇的保肌底线。脂肪通过天然食物自然摄入，碳水优先放在训练前后。

### 3.2 进食时间轴

```
06:30  起床，300ml温水
06:45-07:15  家中动感单车30min（空腹低强度有氧）
07:30  早餐
08:30-09:00  休息消化
09:00-10:30  健身房力量训练
10:30-10:45  可选：健身房爬楼机15min
11:00  练后餐（蛋白粉+快碳）
12:30  午餐
19:00  晚餐
21:00  睡前（如饿：蛋白粉1勺或鸡蛋白3个）
```

### 3.3 库存食物消耗优先级

按以下顺序优先消耗家中库存：

1. **燕麦** 25袋×30g → 早餐每天1-2袋
2. **八宝饭** 2盒 → 练前快碳或早餐，每次半盒-1盒
3. **公司餐** 2盒 → 替代正餐，看热量标签≤300kcal/盒
4. **午餐肉** 4盒 → 替代蛋白，每次半盒-1盒，每周≤2次
5. **腊肉** 4块 → 每周≤1次，每次50g，不再加盐
6. **香肠** 6根 → 每周≤1次，每次半根(80-100g)，水煮去盐

> **5/22起婚礼前一周，彻底停掉腊肉、香肠、午餐肉**，严格控制钠摄入，防止脸部和腹部水肿。

### 3.4 大米生熟换算

- 熟米饭 ≈ 干大米 × 2.5
- 标准晚餐：干米60g → 熟饭150g
- 标准午餐：干米80g → 熟饭200g
- 训练日加量：干米100g → 熟饭250g

## 四、训练原则

### 4.1 分化结构

采用**三分化（推/拉/腿）**，练3休1循环。

| 训练日 | 肌群 | 力量时长 | 腹部 | 早上有氧 |
|:---|:---|:---:|:---:|:---:|
| 推日 | 胸(上胸重点) + 肩中束 + 三头 | 50min | 10min | 单车30min |
| 拉日 | 背(厚度重点) + 肩后束 + 二头 | 50min | 10min | 单车30min |
| 腿日 | 股四 + 腘绳 + 臀 + 小腿 | 55min | 10min | 单车25-30min |
| 休息日 | — | — | 可选 | 可选慢骑20min或散步 |

### 4.2 四周周期

| 周次 | 阶段 | 策略 |
|:---:|:---|:---|
| 第1-2周 | 适应期 | 12-15次/组，RPE 7-8，打磨动作 |
| 第3周 | 容量期 | 10-12次/组，每周增重2.5-5kg，RPE 8-9 |
| 第4周 | 冲刺期 | 12-15次/组，早上单车延至35min，力量后爬楼机20min（二选一也可） |

> 组间休息：复合动作90-120s，孤立动作60-90s。第4周不缩短组间休息。

### 4.3 装备使用规范

- **举重腰带**：深蹲、罗马尼亚硬拉必戴
- **护腕**：杠铃平板卧推必戴
- **助力带**：高位下拉、所有划船类动作佩戴
- 摇摇杯 + 2L以上运动水壶

### 4.4 动作执行原则

1. 动作质量 > 重量，宁轻勿假
2. 离心控制3秒（下放过程）
3. 复合动作优先，孤立动作收尾
4. 渐进超负荷：每周尝试增重或增次
5. 训练中任何关节刺痛立即停止

### 4.5 安全与禁忌

- 空腹有氧如头晕恶心，立即停止，吃香蕉，之后改到早餐后做
- 深夜独练不冲1RM极限重量
- 杠铃深蹲/卧推使用保护架或史密斯机
- 减脂期力量允许下降5-10%，标准第一
- 婚礼前一周（5/22起）彻底停高钠食品

## 五、反馈与调整机制

用户每天使用 `打卡记录.md` 模板反馈以下内容：

- 训练动作、重量、组数、次数
- 饮食记录与营养素估算（蛋白质/碳水/脂肪）
- 饮水量
- 早起空腹体重
- 睡眠时长与质量、疲劳程度

AI根据反馈实时调整：
- 体重连续3天不降 → 检查碳水/脂肪是否超量，或增加有氧
- 力量持续下降 → 检查睡眠和蛋白质，必要时减至一周5练
- 关节疼痛 → 替换动作或减负
- 极度疲劳/失眠 → 增加休息日，降低容量
