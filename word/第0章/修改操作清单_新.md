**ResNet部分需补充**：
```
ResNet通过引入残差连接解决了深层网络的梯度消失问题[27]。残差块的核心思想是
引入恒等映射，残差块的数学表达如公式（3-1）所示：

y = F(x, {W_i}) + x                                     (3-1)

式中：x为输入特征；F(x, {W_i})为残差映射；y为输出特征。

ResNet-50包含4个残差阶段，对于古树名木图像检索任务，在计算效率和特征表达
能力之间取得了良好平衡。
```

**ViT部分需补充**：
```
ViT将图像分割为固定大小的Patch，通过自注意力机制捕获全局依赖关系[30]，
对于古树名木整体形态特征的建模具有优势。自注意力计算如公式（3-2）所示：

Attention(Q,K,V) = softmax(QK^T/√d_k)V                 (3-2)

式中：Q、K、V分别为查询、键、值矩阵；d_k为维度缩放因子。
```

**EfficientNet部分需补充**：
```
EfficientNet通过复合缩放策略统一调整网络深度、宽度和分辨率[31]，
在精度与效率之间取得平衡，适合资源受限场景。
```

```
结构为2→128→128→256，与3.2.1节描述保持一致。
```

## 二、3.2.3 哈希层设计 - 修改清单

### 2.1 必须修改项

#### （1）补充连续松弛策略说明（新增约150字）

```
哈希层设计的核心挑战在于二进制哈希码的离散特性导致不可微。借鉴HashNet[8]的
连续松弛策略，本模型采用"训练阶段连续、推理阶段离散"的两阶段策略。
```

#### （2）补充三段式结构说明（新增约100字）

```
哈希层采用"FC→Tanh→Sign"三段式结构：训练时通过Tanh输出[-1,1]连续值保证梯度传播；
推理时通过Sign函数量化为离散值。
```

#### （3）补充量化损失说明（新增约100字）

```
量化损失用于度量连续值h与离散哈希码sign(h)之间的差距，引导网络生成"接近二进制"
的连续输出，减小训练-推理鸿沟。
```

## 三、3.2.4 损失函数设计 - 修改清单【重点章节】

### 3.1 必须大幅扩充（新增约900字）

#### （1）Triplet Loss详细说明

```
（1）Triplet Loss（三元组损失）

Triplet Loss通过构建三元组（锚点、正样本、负样本）学习判别性特征[28]。
对于锚点样本x_a，从同类别选取正样本x_p，从不同类别选取负样本x_n。

L_triplet = Σ max(||h_a - h_p||² - ||h_a - h_n||² + margin, 0)    (3-6)

式中：h_a、h_p、h_n分别为锚点、正样本、负样本的哈希码；
margin为间隔参数，控制正负样本距离间隔，本文设置margin=0.5。
```

#### （2）Contrastive Loss详细说明

```
（2）Contrastive Loss（对比损失）

Contrastive Loss直接约束同类和异类样本的距离[29]，与Triplet Loss形成互补。

L_contrastive = (1/N)Σ[y_i·d_i² + (1-y_i)·max(margin-d_i, 0)²]    (3-7)

式中：y_i∈{0,1}为样本对标签（1表示同类）；d_i为样本对欧氏距离；
margin为间隔参数，本文设置margin=1.0。
```

#### （3）Quantization Loss补充【原文缺失】

```
（3）Quantization Loss（量化损失）

为降低连续松弛带来的量化误差，引入量化损失约束哈希码逼近二进制值[8]。

L_quant = (1/L)Σ|||h_i| - 1||_1                                 (3-8)

式中：|h_i|表示哈希码元素绝对值；||·||_1表示L1范数。
```

#### （4）在线难例挖掘补充【原文过于简略】

```
（4）在线难例挖掘策略

为提高训练效率并缓解类别不平衡问题，采用在线难例挖掘策略[33]。
在每个训练批次中，动态选择当前模型最难区分的Top-K个样本对参与损失计算。
难例挖掘使模型更关注难分样本，有效缓解古树名木数据的长尾分布问题。
```

#### （5）联合损失函数补充

```
（5）联合损失函数

L_total = λ_1·L_triplet + λ_2·L_contrastive + λ_3·L_quant      (3-9)

式中：λ_1=1.0、λ_2=0.5、λ_3=0.1为权重系数，经验证集网格搜索确定。
```

### 4.2 必须修改项

#### （1）地理位置元数据编码扩充（新增约200字）

```
（1）地理位置元数据编码

地理位置元数据（经纬度坐标）是古树名木检索的重要辅助特征。同种古树往往分布
在相似地理区域，位置信息能够有效补充视觉特征的不足。

采用MLP进行编码，结构为2→128→128→256：
h₁ = ReLU(W₁·[lat; lon] + b₁)                                  (3-10)
h₂ = ReLU(W₂·h₁ + b₂)                                         (3-11)
f_geo = W₃·h₂ + b₃                                            (3-12)

式中：f_geo∈R^256为位置特征向量。
```

#### （2）特征融合方法扩充（新增约200字）

```
（2）特征融合方法

① 特征拼接（主方法）：
ffused = [f_img; f_geo]                                       (3-13)

以ViT为例，f_img∈R^768，f_geo∈R^256，融合后ffused∈R^1024，
经FC层映射至512维后输入哈希层。

② 向量融合（备选方法）：
通过自适应权重动态调整模态贡献：
α_img = σ(W_att·[f_img; f_geo] + b_att)                       (3-14)
ffused = α_img·f_img + (1-α_img)·f_geo                        (3-15)

实验表明特征拼接方法简单有效，作为主模型采用。
```

### 5.1 必须修改项

#### （1）浮点特征检索扩充（新增约150字）

```
（1）浮点特征检索

使用连续值哈希码计算余弦相似度：
sim_cos = (q·d)/(||q||·||d||)                                 (3-16)

计算复杂度O(d)=O(128)，精度高但计算量较大。
```

#### （2）哈希码检索扩充（新增约150字）

```
（2）哈希码检索

使用二值化哈希码计算汉明距离：
d_ham = (1/L)Σ(q_i ⊕ d_i)                                     (3-17)

式中：⊕表示按位异或运算。汉明距离可通过CPU指令POPCNT快速计算，
单次比较约1-2个时钟周期，速度比浮点计算快约100倍。
```

#### （3）多级检索策略扩充（新增约200字）

```
（3）多级检索策略

第一阶段使用汉明距离快速筛选候选集（阈值τ=0.15，返回Top-100）；
第二阶段对候选集使用余弦相似度精排序。

该策略在精度损失小于0.5%的前提下，检索速度提升约50倍。
```
