### 2.2 修改后摘要全文（中文）

```
古树名木是自然生态与历史文化的重要载体，其保护与管理对生物多样性维护和
文化遗产传承具有重要意义。当前，园林局与林业管理部门在古树名木的建设、
检索与管理中，仍普遍依赖人工巡查与纸质记录方式，存在图像与地理位置元数据
割裂、数据更新滞后、品种检索效率低等问题。由于部分古树品种形态相似，且
部分记录信息仅以非结构化图像或孤立的位置坐标形式保存，传统单模态检索方法
难以满足实际精细化管理的需求。因此，构建一个融合图像与地理位置元数据的
多模态检索系统，通过深度哈希网络实现模态间信息融合，成为提升古树名木
保护与管理高效化的关键突破口。本文提出一种基于深度哈希学习的多模态检索模型
（Deep Hashing Learning Attention Multi-modal Network，简称DHLAM），
通过将多模态融合技术融入哈希检索框架，实现以图搜位置、以位置搜图的双向
检索能力。本文主要工作如下：

（1）针对古树名木多模态检索中样本类别不平衡与复杂背景干扰等问题，提出
DHLAM模型。首先，设计基于Triplet Loss和Contrastive Loss的联合损失函数进行
度量学习优化，并采用难例挖掘策略缓解类别不平衡问题。其次，构建哈希层
（FC-Tanh-Sign）和量化损失（Quantization Loss）模块，将连续特征映射为128位
二进制哈希码，降低存储成本并加速检索。最后，设计多模态注意力融合机制，
联合图像和地理位置元数据构建统一语义空间，增强模型对古树关键特征的判别能力。

（2）为系统评估模型性能，构建多维度实验验证框架。首先，将DHLAM与HashNet、
DCH、MDSH三个深度哈希基线模型进行性能对比，验证架构优越性。其次，在
iNaturalist 2018数据集以及自建BFATH数据集上进行mAP@K、Recall@K和
Precision@K指标对比，验证模型有效性。最后，进行消融实验验证哈希层、
注意力融合机制及联合损失函数等各模块的贡献。实验结果表明，DHLAM在检索
速度和准确率上均优于对比方法。

（3）针对现有系统缺少专用古树名木检索工具的问题，设计实现基于B/S架构的
古树名木检索系统。系统采用Vue和SpringBoot前后端分离架构，集成DHLAM模型
支持图像与地理位置双向检索。目前系统已完成开发和测试，运行稳定。

关键词: 古树名木检索，深度哈希学习，多模态哈希检索，DHLAM模型，地理位置元数据
```

1.2.2 多模态融合研究现状

多模态融合是指将来自不同感知通道的信息进行有机结合，以获得比单一模态
更丰富、更鲁棒的特征表示。在古树名木检索场景中，图像提供视觉外观信息，
地理位置元数据提供空间分布信息，二者融合可实现更精准的特征表征。

（1）基于早期融合的多模态方法
早期融合方法在特征提取阶段即对多模态数据进行拼接或加权组合。在位置信息
编码方面，传统方法采用独热编码或分桶编码将地理坐标离散化，再与视觉特征
进行拼接。2014年的研究提出了基于特征拼接的多模态检索框架，通过最小化
模态间分布差异实现特征对齐。

（2）基于注意力机制的多模态融合方法
近年来，注意力机制被广泛应用于多模态融合领域。通道注意力、空间注意力等
机制可有效建模不同模态间的相关性。2018年以来，研究者提出了基于门控机制
的多模态融合方法，通过可学习的门控单元动态调节各模态特征的贡献度。

（3）基于统一空间学习的多模态哈希方法
深度哈希学习为多模态融合提供了统一框架。2017年HashNet引入连续化优化策略，
有效缓解二值化过程中的量化误差。2018年DCH方法基于柯西分布设计成对损失函数。
2023年MDSH方法采用多尺度深度监督策略，在多个基准数据集上取得当前最优性能。

本文提出的DHLAM模型正是在此背景下，针对古树名木的图像-地理位置多模态融合
需求，设计位置编码器与视觉特征融合机制，实现高效的多模态检索。
```

### 2.3.3 地理位置元数据编码方法

地理位置元数据（Geographic Metadata）以经纬度坐标形式记录图像拍摄位置。
为将其融入深度哈希学习框架，需要设计专门的位置信息编码模块，将二维坐标
映射为高维特征向量。

**（1）坐标归一化**
原始经纬度（纬度范围[-90°, 90°]，经度范围[-180°, 180°]）需先归一化到[0,1]范围：
    lat_norm = (lat + 90) / 180
    lon_norm = (lon + 180) / 360

**（2）位置编码网络结构**
采用多层感知机（MLP）将归一化后的2D坐标映射为256维位置特征：
    LocationEncoder: R^2 → R^256
    结构：FC(2→128) → ReLU → FC(128→128) → ReLU → FC(128→256)

**（3）位置嵌入的物理意义**
位置编码网络学习目标是将地理空间上相近的样本映射为相似的特征向量，
从而将地理位置的邻近关系转化为特征空间的相似性关系，为后续的模态融合
奠定基础。
```
