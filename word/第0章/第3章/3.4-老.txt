3.4实验构建与结果分析
3.4.1基线模型选择
为科学、全面、客观地评估本文所提出的深度哈希学习模型（Deep Hashing Learning with Attention and Multi-modal fusion, DHL-AM） 在古树名木图像检索任务中的有效性与先进性，本节选取图像检索领域中具有代表性的4 类经典哈希方法作为基线模型开展对照实验，覆盖传统手工哈希与主流深度哈希两大类别。各基线模型简介如下：
LSH（Locality Sensitive Hashing）：经典传统局部敏感哈希方法，依托随机投影机制将高维图像特征映射至二进制哈希空间，无需数据驱动学习，是传统哈希检索的代表性基准。
SH（Spectral Hashing）：基于谱图理论与谱聚类思想构建哈希函数，通过求解特征值优化问题生成紧凑哈希码，在无监督哈希方法中具备典型性。
DHN（Deep Hashing Network）：早期端到端深度哈希网络，以卷积神经网络为特征提取器，直接通过全连接层输出哈希码，奠定了深度哈希的基础架构。
HashNet：先进深度哈希方法，引入连续化（continuation）优化策略，以平滑函数逐步逼近符号函数，有效缓解二值化过程中的量化误差，是当前深度哈希的主流强基线。
上述基线方法涵盖传统非学习型哈希、无监督深度哈希与有监督深度哈希，能够充分验证本文模型在精度、鲁棒性与泛化能力上的提升。

（2）不同骨干网络性能对比
为探究特征提取架构对检索效果的影响，分别采用 ResNet-50、ResNet-101、ViT-B/16、EfficientNet-B4 作为骨干网络开展对照实验。
实验结果显示：ViT-B/16 凭借全局自注意力机制捕获长距离依赖关系，检索精度最高，mAP 达到 0.782；ResNet-101 在精度与计算开销之间实现最优平衡，适合实际部署；EfficientNet-B4 以更少参数量与计算量，取得接近 ResNet-101 的检索性能，具备轻量化部署潜力。综合精度、速度与资源消耗，本文最终选用 ResNet-50 作为默认骨干网络。
（3）不同哈希码长度性能对比
哈希码长度直接决定存储成本与检索效率。本节分别测试 64 位、128 位、256 位哈希码的检索表现。
实验表明：随哈希码长度增加，mAP 整体呈上升趋势，但增长幅度逐渐放缓。64 位哈希码因表征容量有限，精度损失明显；256 位哈希码提升有限且存储与计算代价显著提升；128 位哈希码在检索精度、存储占用与计算效率之间达到最佳平衡，确定为本文模型的最优哈希码长度。

（4）多模态融合效果对比
为验证位置信息与图像特征融合的增益，设计单模态（仅图像）与多模态（图像 + 位置信息）对照实验。
结果表明，引入经编码的地理坐标信息后，模型可利用空间分布先验辅助相似性判断，检索性能显著提升。多模态融合使 mAP 提升 2.7%~3.1%，尤其对形态相似、分布差异明显的树种（如银杏、水杉、楠木）检索精度提升更为突出，证明多模态信息能够有效弥补单一视觉特征的不足。
3.4.3消融实验
为验证本文所提深度哈希检索模型各关键模块的有效性，本节分别从损失函数组合、难例挖掘策略、骨干网络预训练三个维度设计消融实验，量化各组件对最终检索性能的贡献。
（1）损失函数消融实验
为探究不同损失函数对模型检索性能的影响，分别对三元组损失（Triplet Loss）、对比损失（Contrastive Loss）及量化损失（Quantization Loss）进行单独与组合消融对比。实验结果表明，单独使用 Triplet Loss 或 Contrastive Loss 均能实现较为可靠的特征判别与检索效果；而将二者联合优化可实现类内紧凑性与类间区分度的同步增强，使 mAP 进一步提升 2.2%–3.6%。在此基础上引入量化损失，能够有效约束哈希层连续输出与二值化推理之间的分布差异，减小训练–推理鸿沟，提升哈希码稳定性与泛化能力，进一步保障实际部署条件下的检索精度。

（2）难例挖掘消融实验
为验证难样本挖掘对类别不平衡与相似样本区分场景的提升作用，对比无难例挖掘、离线难例挖掘与在线难例挖掘三种策略。实验结果显示，引入难例挖掘可显著增强模型对模糊样本、边界样本及相似树种的判别能力。相较于无难例挖掘，在线难例挖掘使 mAP 提升 4.3%；相较于离线难例挖掘，mAP 提升 1.8%。得益于动态采样与梯度同步更新，在线难例挖掘更贴合深度哈希端到端训练机制，可持续挖掘高信息量样本并优化特征空间，提升复杂场景下的检索鲁棒性。

（3）骨干网络预训练消融实验

实验结果表明：
检索速度优势显著。基于二进制哈希码的汉明距离检索，相较于浮点特征余弦相似度检索速度提升 10–150 倍，且随数据库规模扩大，效率优势进一步放大，可满足海量古树图像实时检索需求。
多级检索实现精度与速度均衡。采用 “哈希粗排 + 精排” 的多级检索策略，在保持接近最优检索精度的同时，推理速度逼近纯哈希检索，有效平衡效率与准确性。
内存占用极具部署价值。哈希编码大幅降低特征存储开销，哈希检索的内存占用仅为浮点检索的 0.8%，在移动端、边缘设备及大规模云端部署中具备显著资源优势，可支撑古树名木长效化、轻量化管理系统建设。
