### 【CRITICAL-2】公式(2-2)格式严重错误 ⚠️ 高风险

**问题描述**：
公式(2-2)的LaTeX代码存在多处格式错误，包括：
1. 末尾多余"+"号
2. 上下标未正确标注（应使用`_i^a`而非`ai`）
3. 正号`[+]`表示不规范

**定位位置**：
```
第61行
原文：
Ltriplet=‖f(xai)−f(xpi)‖22−‖f(xai)−f(xni)‖22+α+ 	（2-2）
```

**修改方案**：
```
规范LaTeX格式：
L_{triplet} = \|f(x_i^a) - f(x_i^p)\|_2^2 - \|f(x_i^a) - f(x_i^n)\|_2^2 + \alpha]_+

解释：
- 使用`_i^a`表示下标i、上标a
- 使用`\| \|_2^2`表示L2范数平方
- 使用`]_+`表示max(·, 0)操作
```

### 3.3 公式格式问题

#### 问题10：公式(2-3)缺少求和符号
**位置**：第71行  
**原文**：`Lcontrastive=1Ni=1Nyi⋅D(xi1,xi2)2+(1−yi)⋅[m−D(xi1,xi2)]+2`  
**问题**：`i=1N`应为`\sum_{i=1}^{N}`，整体缺少求和符号  
**修改**：
```
L_{contrastive} = \frac{1}{N} \sum_{i=1}^{N} \left[ y_i \cdot D(x_i^1, x_i^2)^2 + (1-y_i) \cdot [m - D(x_i^1, x_i^2)]_+^2 \right]
```

#### 问题13：公式(2-13)符号不规范
**位置**：第161行  
**原文**：`z=vTWu 或 B=v⊗u=vuT`  
**问题**：
1. 外积符号`⊗`应使用`\otimes`

```
z = v^T W u \quad \text{或} \quad B = v \otimes u = v u^T
```
