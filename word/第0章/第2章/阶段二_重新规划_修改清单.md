#### （1）ResNet系列补充公式和图片说明

在现有内容后添加：
```
ResNet通过残差连接解决深层网络的梯度消失问题。残差块的数学表达如公式（2-8）所示：
y=F(x,Wi)+x（2-8）
其中，x为输入特征，F(x,Wi)为残差映射，y为输出特征。残差连接通过跳过连接（Skip Connection）将输入直接加到输出上，有效缓解了深层网络的梯度消失问题。

ResNet-50在深度哈希学习中是最常用的选择，在特征表达能力和计算效率之间取得良好平衡。ResNet-101和ResNet-152则适用于对特征表达能力要求更高的场景。
```

#### （2）ViT系列补充详细介绍

在现有内容后添加：
```
ViT通过多层Transformer编码器处理图像块序列，每一层包含多头自注意力（Multi-Head Self-Attention，MSA）和前馈神经网络（MLP）。自注意力机制的计算如公式（2-3）所示：
Attention(Q,K,V)=softmax(QKT/dk)V（2-3）
其中，Q、K、V分别为查询、键、值矩阵，dk为键的维度。

ViT的主要变体包括ViT-Base（12层Transformer，隐藏维度768，参数量86M）和ViT-Large（24层Transformer，隐藏维度1024，参数量307M）。ViT在大型数据集上预训练后，能够提取具有全局感受野的图像特征，在深度哈希学习中展现出优异的性能。
```

#### （3）EfficientNet系列补充公式

在现有内容后添加：
```
EfficientNet的复合缩放公式如公式（2-4）所示：
d=αφ,w=βφ,r=γφ（2-4）
其中，d、w、r分别表示深度、宽度、分辨率的缩放系数，φ为复合系数，α、β、γ为常数。EfficientNet使用移动倒置瓶颈卷积（Mobile Inverted Bottleneck Convolution，MBConv）作为基础构建块，在ImageNet数据集上取得了当时的最优性能。

EfficientNet-B0到B7提供了不同计算复杂度的选择，在相同准确率下参数量和计算量显著低于其他网络。EfficientNet-B3和EfficientNet-B4在深度哈希学习中是常用的选择，兼顾了特征表达能力和计算效率。
```
